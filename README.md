# -Cali-La-Sucursal-Natural-Novela-Visual-Interactiva-
Estamos desarrollando un prototipo de novela visual interactiva para promover la biodiversidad, la fauna, la flora y los ríos de Santiago de Cali. Tu opinión es fundamental para evaluar qué tan atractiva y útil es esta experiencia digital tanto para residentes como para turistas.
